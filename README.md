##### SELECTED PROMPT #####
Industrial Systems - 3D Printing for Aerospace

An aerospace contractor 3D-printing titanium brackets is failing client strength tests. They don't currently track enough environmental and stress parameters against final part strength. Design a tool to monitor and flag when and whether the printing process is capable of meeting strict aerospace tolerances, and help contractors resolve these issues.

##### EXPLANATION OF TOOL #####
"AeroPrint QC" is a custom dashboard that evaluates process capability of 3D-printed titanium brackets. It accepts a CSV of data and minimum requirements on strength (MPa) and process capability (CpK) and outputs valuable process statistics such as mean strength, CpK, and PpK. The output also indicates the number of prints below minimum and number of Out-of-Control (OOC) prints.
