# AeroPrint QC — Cornell Six Sigma Hackathon

A working Streamlit dashboard for screening strength capability of additively manufactured titanium brackets. Built with AI assistance for an educational hackathon; not approved for aircraft qualification.

## Quick start

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

Select any of the three demo datasets, adjust the **illustrative** 900 MPa minimum strength and 1.33 capability target, or upload a CSV matching `data/CODEBOOK.md`.

## Statistical functions (`qc.py`)

- `validate(df)`: checks required fields, numeric completeness, at least 10 specimens and 3 builds, and basic physical constraints. Returns cleaned dataframe.
- `analyze(df, lsl=900, target_cpk=1.33)`: computes mean, sample overall standard deviation, pooled within-build standard deviation, **one-sided** Cpk = (mean - LSL)/(3 × within SD), and Ppk = (mean - LSL)/(3 × overall SD). With only a lower limit, Cp and Pp are not defined. A positive margin alone does not imply qualification.
- I-chart of sequential build means: moving-range sigma = mean absolute adjacent build-mean difference / 1.128; center and ±3 sigma limits. Flags points beyond limits. **Caution:** This is a screening chart, not a complete SPC study; no additional run rules or autocorrelation assessment. Within-build pooling assumes meaningful rational subgroups.
- Failure count: observed coupons below the user-selected lower limit.
- Parameter screening: specimen-level Pearson r with exploratory naive p-values. Correlations are not proof of causality; within-build clustering violates independent-observation assumptions for naive p-values. Follow up with build-level analysis or a mixed model and designed experiments.

## Three test datasets

1. `data/stable_capable.csv` — relatively high, consistent strength.
2. `data/oxygen_drift.csv` — higher oxygen after build 13 and a shift in strength.
3. `data/high_variation.csv` — greater variation in oxygen and tensile strength.

All data are **synthetic**, generated by `python generate_data.py` with fixed seeds. See `data/CODEBOOK.md` for field definitions, units, and collection instructions.

## Test and reproduce

```bash
python generate_data.py
python -m pytest -q
streamlit run app.py
```

## Demo walkthrough

1. Load Stable / capable. Observe strength histogram, build-average chart and capability screening.
2. Switch to Oxygen drift. Review SPC/capability alerts and identify suspect builds.
3. Switch to High variation. Compare within/overall spread and parameter correlations.
4. Change minimum strength to demonstrate specification sensitivity.
5. Upload a CSV with the codebook columns, and download its cleaned analysis input.

## Engineering limits

This app does not calculate qualified design allowables, certify aerospace components, perform fatigue or fracture mechanics evaluation, control for build clustering in parameter p-values, or establish calibration and traceability. A real deployment requires engineering approval, verified specifications, machine/material/process traceability, representative sampling, measurement system analysis, independent validation, and controlled process changes.

## Deployment

Deploy this Streamlit app to a Python-capable hosting service or your course Posit Connect environment using publisher credentials. Publishing and GitHub repository creation require your account access and are not performed by this package.
